پنل ادمین — منوی هانی‌مون

این صفحه مستقیم به ریپازیتوری گیت‌هابت وصله. هر تغییری که ذخیره کنی، خودکار روی GitHub Pages، Cloudflare و Vercel هم به‌روز میشه.

اتصال به گیت‌هاب

چطور توکن بسازم؟
  1. برو به github.com → روی عکس پروفایلت → Settings
  2. پایین صفحه: Developer settings
  3. Personal access tokens → Fine-grained tokens → Generate new token
  4. در Repository access: فقط ریپازیتوری Honeymoon-menu رو انتخاب کن
  5. در Permissions: کنار Contents، گزینه‌ی Read and write رو بزن
  6. Generate token و کد رو کپی کن (فقط یه‌بار نشون داده میشه)
